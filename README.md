# ระบบจัดการหอพัก (Dormitory Management System)

ระบบบริหารจัดการหอพักสำหรับผู้ดูแลและผู้พักอาศัย พัฒนาด้วยภาษา Java โดยมีวัตถุประสงค์เพื่อช่วยจัดการข้อมูลห้องพัก ผู้เช่า สัญญาเช่า ค่าน้ำ-ค่าไฟ การชำระเงิน การแจ้งซ่อม การย้ายห้อง และข้อมูลรายรับ-รายจ่ายของหอพัก

## 2. ผู้ใช้งานระบบ

ระบบแบ่งผู้ใช้งานออกเป็น 3 ประเภท ได้แก่

### 2.1 ผู้สนใจเข้าอาศัย (Applicant)

* ดูข้อมูลและราคาห้องพัก
* ตรวจสอบสถานะห้องพัก
* ส่งคำขอจองห้องพัก

### 2.2 ผู้พักอาศัย (Tenant)

* ดูข้อมูลห้องพักและสัญญาเช่า
* ดูประวัติการใช้น้ำและไฟ
* ดูใบแจ้งหนี้และสถานะการชำระเงิน
* ส่งหลักฐานการชำระเงิน
* แจ้งซ่อมและร้องเรียน
* ยื่นคำขอย้ายห้อง

### 2.3 ผู้ดูแลหอพัก (Admin)

* จัดการข้อมูลห้องพัก
* จัดการข้อมูลผู้เช่าและสัญญาเช่า
* บันทึกมิเตอร์น้ำและไฟ
* คำนวณและออกใบแจ้งหนี้
* ตรวจสอบและยืนยันการชำระเงิน
* พิจารณาคำขอย้ายห้อง
* จัดการคำร้องเรียนและแจ้งซ่อม
* บันทึกรายรับ-รายจ่าย
* ดูรายงานและ Dashboard

## 3. ฟังก์ชันหลักของระบบ

1. ระบบเข้าสู่ระบบและกำหนดสิทธิ์ตามประเภทผู้ใช้งาน
2. ระบบจัดการข้อมูลห้องพักและสถานะห้อง
3. ระบบจัดการข้อมูลผู้เช่าและสัญญาเช่า
4. ระบบบันทึกมิเตอร์น้ำและไฟ
5. ระบบคำนวณค่าเช่า ค่าน้ำ และค่าไฟ
6. ระบบออกใบแจ้งหนี้ประจำเดือน
7. ระบบตรวจสอบการชำระเงิน
8. ระบบแจ้งซ่อมและร้องเรียน
9. ระบบขอย้ายห้อง
10. ระบบสรุปรายรับ-รายจ่ายและอัตราการเข้าพัก

### สูตรการคำนวณ

```text
หน่วยที่ใช้ = เลขมิเตอร์ปัจจุบัน - เลขมิเตอร์เดือนก่อน

ยอดรวมบิล = ค่าเช่า
           + (หน่วยน้ำ × อัตราค่าน้ำ)
           + (หน่วยไฟ × อัตราค่าไฟ)

กำไรสุทธิ = รายได้ - รายจ่าย

อัตราการเข้าพัก =
(จำนวนห้องที่มีผู้เช่า ÷ จำนวนห้องทั้งหมด) × 100
```

## 6. แนวคิดด้านการเขียนโปรแกรมเชิงวัตถุ

โครงงานประยุกต์ใช้หลักการเขียนโปรแกรมเชิงวัตถุ ได้แก่

* **Encapsulation** ใช้ `private fields` และ Getter/Setter ในการจัดการข้อมูล
* **Inheritance** โดยมี `User` เป็นคลาสหลัก และมี `Admin`, `Tenant` และ `Applicant` เป็นคลาสย่อย
* **Polymorphism** เพื่อให้ผู้ใช้งานแต่ละประเภทสามารถทำงานแตกต่างกันตามสิทธิ์
* **Exception Handling** เพื่อจัดการข้อผิดพลาดจากการกรอกข้อมูลและการอ่านหรือเขียนไฟล์
