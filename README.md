# ระบบจัดการหอพัก (Dormitory Management System)

ระบบบริหารจัดการหอพักแบบครบวงจร ออกแบบมาเพื่ออำนวยความสะดวกแก่ผู้ดูแลหอพักและผู้เช่า ครอบคลุมการจัดการข้อมูลห้องพักและสัญญาเช่า การบันทึกค่าน้ำ-ค่าไฟพร้อมออกใบแจ้งหนี้อัตโนมัติ ระบบคำร้องเรียนและแจ้งซ่อม การขอย้ายห้อง รวมถึงรายงานและกราฟสรุปรายรับ-รายจ่ายและอัตราการเข้าพัก 

ระบบแบ่งสิทธิ์การใช้งานตามบทบาทของผู้ใช้ เพื่อให้แต่ละคนเข้าถึงได้เฉพาะฟังก์ชันที่เกี่ยวข้อง พัฒนาด้วยภาษา Java แสดงผลผ่าน Java Swing และเก็บข้อมูลในไฟล์ CSV

## 2. ผู้ใช้งานระบบ

ระบบแบ่งผู้ใช้งานออกเป็น 3 กลุ่ม ได้แก่ ผู้สนใจเข้าอาศัย ผู้พักอาศัย และผู้ดูแลหอพัก

### 2.1 ผู้สนใจเข้าอาศัย (Guest / Applicant)

ผู้ที่สนใจเช่าห้องพัก สามารถตรวจสอบข้อมูลห้องและส่งคำขอจองได้ โดยทำสิ่งต่อไปนี้ได้

* ดูรายการห้องพักและประเภทห้อง
* ดูราคาค่าเช่ารายเดือน
* ตรวจสอบสถานะห้อง (ว่าง, มีผู้เช่า, อยู่ระหว่างปรับปรุง)
* ส่งคำขอจองห้องพร้อมข้อมูลเบื้องต้น

### 2.2 ผู้พักอาศัย (Tenant)

ผู้เช่าเข้าสู่ระบบเพื่อดูและจัดการข้อมูลการพักอาศัยของตนเองได้ ดังนี้

* ดูข้อมูลห้องพักของตนเอง
* ดูรายละเอียดสัญญาเช่า เช่น วันเริ่มต้น วันสิ้นสุด ค่าเช่า และเงินประกัน
* ดูประวัติการใช้น้ำและไฟ
* ดูใบแจ้งหนี้ประจำเดือนและตรวจสอบสถานะการชำระเงิน
* ส่งหลักฐานการชำระเงิน
* ยื่นคำขอย้ายห้อง
* แจ้งซ่อมหรือร้องเรียน พร้อมติดตามสถานะของคำร้อง

### 2.3 ผู้ดูแลหอพัก (Admin / Owner)

ผู้ดูแลมีสิทธิ์จัดการข้อมูลหลักทั้งหมดและติดตามการดำเนินงานของหอพัก ดังนี้

* เพิ่ม แก้ไข และเปลี่ยนสถานะห้องพัก
* จัดการข้อมูลผู้เช่าและสัญญาเช่า
* บันทึกเลขมิเตอร์น้ำและไฟ
* คำนวณและออกใบแจ้งหนี้อัตโนมัติ
* ตรวจสอบและยืนยันการชำระเงิน
* พิจารณาคำขอย้ายห้อง
* จัดการคำร้องเรียนและงานแจ้งซ่อม
* บันทึกรายจ่ายของหอพัก
* ดูรายงานและ Dashboard

## 3. ฟังก์ชันหลักของระบบ

### 3.1 ระบบจัดการห้องพัก

เพิ่ม แก้ไข และตรวจสอบข้อมูลห้อง ได้แก่ หมายเลขห้อง ประเภทห้อง ค่าเช่า และสถานะห้อง

```text
AVAILABLE      ห้องว่าง
OCCUPIED       มีผู้เช่า
MAINTENANCE    อยู่ระหว่างปรับปรุง
```

### 3.2 ระบบจัดการผู้เช่าและสัญญาเช่า

เก็บข้อมูลผู้เช่า (ชื่อ-นามสกุล เบอร์โทรศัพท์ ห้องที่พัก) และข้อมูลสัญญา (วันเข้าพัก วันสิ้นสุดสัญญา ค่าเช่ารายเดือน เงินประกัน และสถานะสัญญา)

ระบบตรวจสอบสัญญาที่ใกล้หมดอายุได้ เช่น ภายใน 30 วัน เพื่อให้ผู้ดูแลต่อสัญญาหรือแจ้งผู้เช่าได้ทันเวลา

### 3.3 ระบบค่าน้ำและค่าไฟ

ผู้ดูแลบันทึกเลขมิเตอร์น้ำและไฟทุกเดือน จากนั้นระบบจะคำนวณหน่วยที่ใช้จากผลต่างของเลขมิเตอร์เดือนปัจจุบันกับเดือนก่อนหน้า

```text
หน่วยที่ใช้ = เลขมิเตอร์ปัจจุบัน - เลขมิเตอร์เดือนก่อน
```

แล้วนำจำนวนหน่วยไปคูณกับอัตราที่กำหนดเพื่อหาค่าใช้จ่าย

### 3.4 ระบบใบแจ้งหนี้

ระบบสร้างใบแจ้งหนี้ประจำเดือนโดยอัตโนมัติจากค่าเช่า ค่าน้ำ และค่าไฟ

```text
ยอดรวมบิล =
ค่าเช่า
+ (หน่วยน้ำ × อัตราค่าน้ำ)
+ (หน่วยไฟ × อัตราค่าไฟ)
```

สถานะของบิล

```text
PENDING                  รอชำระ
VERIFICATION             รอตรวจสอบการชำระเงิน
PAID                     ชำระแล้ว
OVERDUE                  ค้างชำระ
```

### 3.5 ระบบชำระเงิน

ผู้เช่าส่งหลักฐานการชำระเงินผ่านระบบ แล้วผู้ดูแลจะตรวจสอบและยืนยันการชำระเงิน

### 3.6 ระบบขอย้ายห้อง

ผู้เช่าเลือกห้องที่ต้องการย้าย ระบุเหตุผล และส่งคำขอให้ผู้ดูแลพิจารณา

เมื่อผู้ดูแลอนุมัติ ระบบจะอัปเดตข้อมูลสัญญาและสถานะห้องให้อัตโนมัติ

```text
ห้องเดิม  → AVAILABLE
ห้องใหม่  → OCCUPIED
สัญญาเช่า → เปลี่ยนเป็นห้องใหม่
```

### 3.7 ระบบแจ้งซ่อมและร้องเรียน

ผู้เช่าแจ้งปัญหาที่พบได้ เช่น

* อุปกรณ์ภายในห้องชำรุด
* แอร์ไม่เย็น
* น้ำรั่วหรือท่อตัน
* ปัญหาเฟอร์นิเจอร์
* เสียงดังรบกวน
* ปัญหาพื้นที่ส่วนกลาง

สถานะของคำร้อง

```text
PENDING        รอดำเนินการ
IN_PROGRESS    กำลังดำเนินการ
COMPLETED      ดำเนินการเสร็จสิ้น
```

## 4. Dashboard และรายงาน

Dashboard สำหรับผู้ดูแลแสดงภาพรวมของหอพัก ประกอบด้วย

* รายได้และรายจ่ายรายเดือน / รายปี
* กำไรสุทธิ
* อัตราการเข้าพัก
* จำนวนผู้เช่าเข้าใหม่และผู้เช่าย้ายออก
* สถานะการชำระเงิน
* จำนวนคำร้องเรียนแยกตามประเภท

สูตรที่ใช้คำนวณ

```text
รายได้เดือน =
ผลรวมยอดบิลที่มีสถานะ PAID

กำไรสุทธิ =
รายได้ - รายจ่าย

อัตราการเข้าพัก =
(จำนวนห้องที่มีผู้เช่า ÷ จำนวนห้องทั้งหมด) × 100
```

กราฟทั้งหมดวาดด้วย `Graphics2D` บน `JPanel` โดยไม่พึ่งพา Library ภายนอก

## 6. สถาปัตยกรรมของระบบ

ระบบแบ่งเป็นชั้น ๆ เพื่อแยกหน้าที่ของแต่ละส่วนออกจากกัน

```text
User Interface
      ↓
Service / Business Logic
      ↓
Model
      ↓
CSV Storage
```

**ตัวอย่างการเข้าสู่ระบบ (Login)**

```text
LoginPanel
    ↓
AuthManager
    ↓
CSVService
    ↓
users.csv
```

**ตัวอย่างการออกใบแจ้งหนี้**

```text
BillingPanel
    ↓
BillingManager
    ↓
Room / Contract / Meter
    ↓
CSVService
    ↓
bills.csv
```

การแยกส่วนติดต่อผู้ใช้ ส่วนประมวลผล และส่วนจัดเก็บข้อมูลออกจากกัน ช่วยให้พัฒนา ทดสอบ และแก้ไขแต่ละส่วนได้ง่ายขึ้น

## 7. การจัดเก็บข้อมูล

ระบบใช้ไฟล์ CSV แทนฐานข้อมูล โดยแยกไฟล์ตามประเภทของข้อมูล

```text
data/
├── users.csv
├── rooms.csv
├── contracts.csv
├── bills.csv
├── payments.csv
├── bookings.csv
├── complaints.csv
├── room_transfers.csv
└── expenses.csv
```

**ตัวอย่างข้อมูลห้องพัก (`rooms.csv`)**

```csv
roomId,roomNumber,roomType,baseRent,status
R101,101,Air-Conditioned,4500,OCCUPIED
R102,102,Fan,3500,AVAILABLE
R103,103,Air-Conditioned,4500,AVAILABLE
```

**ตัวอย่างข้อมูลผู้ใช้งาน (`users.csv`)**

```csv
userId,username,password,fullName,phone,role,roomId
U001,admin,admin123,สมชาย ใจดี,0812345678,ADMIN,-
U002,tenant101,pass101,กิตติพงษ์ รักสงบ,0898765432,TENANT,R101
U003,applicant1,pass123,อนันต์ มุ่งมั่น,0861112233,APPLICANT,-
```
