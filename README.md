# ระบบจัดการหอพัก (Dormitory Management System)

ระบบบริหารจัดการหอพักแบบครบวงจร ออกแบบมาเพื่ออำนวยความสะดวกแก่ผู้ดูแลหอพักและผู้เช่า ครอบคลุมการจัดการข้อมูลห้องพักและสัญญาเช่า การบันทึกค่าน้ำ-ค่าไฟพร้อมออกใบแจ้งหนี้อัตโนมัติ รวมถึงระบบแจ้งซ่อมและติดตามสถานะออนไลน์

> พัฒนาด้วย **Java ล้วน ๆ** ใช้เฉพาะ JDK มาตรฐาน ไม่ต้องติดตั้งไลบรารีภายนอก ฐานข้อมูลภายนอก หรือเครื่องมือ Build เพิ่มเติม

## ฟีเจอร์หลัก (Features)

### 1. จัดการห้องพักและสัญญาเช่า
- เพิ่ม แก้ไข ลบ และค้นหาข้อมูลห้องพัก
- ดูสถานะห้อง (ว่าง / มีผู้เช่า / ปรับปรุง)
- จัดการข้อมูลผู้เช่าและสัญญาเช่า (วันเริ่ม-สิ้นสุด, ค่าเช่า, เงินประกัน)

### 2. บันทึกค่าน้ำ-ค่าไฟและออกใบแจ้งหนี้
- บันทึกเลขมิเตอร์น้ำและไฟรายเดือน
- คำนวณหน่วยที่ใช้และค่าใช้จ่ายอัตโนมัติ
- ออกใบแจ้งหนี้รายเดือนและติดตามสถานะการชำระเงิน

สูตรการคำนวณใบแจ้งหนี้:

```
หน่วยที่ใช้ = เลขมิเตอร์ปัจจุบัน - เลขมิเตอร์เดือนก่อน
ยอดรวม     = ค่าเช่า + (หน่วยน้ำ × อัตราค่าน้ำ) + (หน่วยไฟ × อัตราค่าไฟ)
```

### 3. ระบบแจ้งซ่อม
- ผู้เช่าแจ้งปัญหาพร้อมรายละเอียด
- ผู้ดูแลอัปเดตสถานะ (รอดำเนินการ / กำลังซ่อม / เสร็จสิ้น)
- ติดตามประวัติการซ่อมของแต่ละห้อง

## การติดตั้งและใช้งาน (Getting Started)

### สิ่งที่ต้องมี (Prerequisites)
- JDK 17 ขึ้นไป (ตรวจสอบด้วย `java -version` และ `javac -version`)

### ขั้นตอนการรันโปรแกรม

1. โคลนโปรเจ็ค
   ```bash
   git clone https://github.com/<username>/<repo-name>.git
   cd <repo-name>
   ```

2. คอมไพล์โค้ดทั้งหมด

   macOS / Linux
   ```bash
   mkdir -p out
   javac -d out $(find src -name "*.java")
   ```

   Windows (Command Prompt)
   ```bat
   mkdir out
   dir /s /b src\*.java > sources.txt
   javac -d out @sources.txt
   ```

3. รันโปรแกรม
   ```bash
   java -cp out Main
   ```

> ไฟล์ข้อมูลจะถูกสร้างในโฟลเดอร์ `data/` อัตโนมัติเมื่อรันโปรแกรมครั้งแรก

## แนวทางการพัฒนา (Development Workflow)

- แตก branch ใหม่สำหรับแต่ละฟีเจอร์ เช่น `feature/invoice`
- เขียน commit message ให้สื่อความหมาย
- เปิด Pull Request และให้เพื่อนในกลุ่มช่วยรีวิวก่อน merge เข้า `main`
- ไม่ commit ไฟล์ในโฟลเดอร์ `out/` (ใส่ไว้ใน `.gitignore`)
