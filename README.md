# ระบบจัดการหอพัก (Dormitory Management System)

ระบบบริหารจัดการหอพักแบบครบวงจร ออกแบบมาเพื่ออำนวยความสะดวกแก่ผู้ดูแลหอพักและผู้เช่า ครอบคลุมการจัดการข้อมูลห้องพักและสัญญาเช่า การบันทึกค่าน้ำ-ค่าไฟพร้อมออกใบแจ้งหนี้อัตโนมัติ ระบบคำร้องเรียนและแจ้งซ่อม การขอย้ายห้อง รวมถึงรายงานและกราฟสรุปรายรับ-รายจ่ายและอัตราการเข้าพัก

## ผู้ใช้งานและฟีเจอร์ (Users & Features)

ระบบแบ่งผู้ใช้งานเป็น 3 บทบาท

### 1. ผู้สนใจเข้าอาศัย (Guest / Applicant)
- ดูรายการห้องพัก ประเภทห้อง และราคาค่าเช่ารายเดือน
- ตรวจสอบสถานะห้อง (ว่าง / มีผู้เช่า / ปรับปรุง)
- ส่งคำขอจองห้องพักพร้อมกรอกข้อมูลเบื้องต้น

### 2. ผู้พักอาศัย (Tenant)
- เข้าสู่ระบบและดูข้อมูลห้องพักของตนเอง
- **ดูข้อมูลสัญญาเช่า** (วันเข้าพัก, วันสิ้นสุดสัญญา, ค่าเช่า, เงินประกัน)
- ดูประวัติการใช้น้ำ-ไฟ (ยูนิตปัจจุบันและยูนิตก่อนหน้า)
- ดูยอดบิลประจำเดือนและสถานะ (ชำระแล้ว / ค้างชำระ / รอตรวจสอบ)
- ส่งหลักฐานการชำระเงิน (แนบชื่อไฟล์สลิป)
- **ยื่นคำขอย้ายห้อง** และติดตามผลการอนุมัติ
- **ยื่นคำร้องเรียน/แจ้งซ่อม** และติดตามสถานะ

### 3. ผู้ดูแลหอพัก (Admin / Owner)
- จัดการข้อมูลห้อง (เพิ่ม / แก้ไข / ปรับสถานะห้อง)
- **จัดการข้อมูลผู้เช่าและสัญญาเช่า** (วันเข้าพัก, ต่อสัญญา, สิ้นสุดสัญญา / แจ้งออก)
- บันทึกมิเตอร์น้ำ-ไฟประจำงวด
- ออกใบแจ้งหนี้อัตโนมัติ (ค่าเช่า + ค่าน้ำ + ค่าไฟ)
- ตรวจสอบและยืนยันการชำระเงินของผู้เช่า
- **พิจารณาคำขอย้ายห้อง** (อนุมัติ / ปฏิเสธ พร้อมหมายเหตุ)
- **จัดการคำร้องเรียน** (อัปเดตสถานะ, บันทึกผลการแก้ไข)
- **บันทึกรายจ่ายของหอพัก** และดูรายงานสรุป

### รายละเอียดฟีเจอร์เพิ่มเติม

#### สัญญาเช่าและข้อมูลผู้เช่า
- ข้อมูลผู้เช่า: ชื่อ-นามสกุล, เบอร์โทร, ห้องที่พัก
- ข้อมูลสัญญา: วันเข้าพัก, วันสิ้นสุดสัญญา, ค่าเช่ารายเดือน, เงินประกัน, สถานะสัญญา (ใช้งานอยู่ / สิ้นสุดแล้ว)
- แจ้งเตือนสัญญาที่ใกล้หมดอายุ (เช่น ภายใน 30 วัน)

#### การขอย้ายห้อง
- ผู้เช่าเลือกห้องว่างที่ต้องการย้ายไป ระบุเหตุผล
- ผู้ดูแลอนุมัติหรือปฏิเสธ เมื่ออนุมัติ ระบบจะอัปเดตห้องในสัญญา สถานะห้องเดิม (ว่าง) และห้องใหม่ (มีผู้เช่า) ให้อัตโนมัติ

#### คำร้องเรียน
| หมวดหมู่ | ตัวอย่าง |
| :--- | :--- |
| อุปกรณ์เสียหาย | แอร์ไม่เย็น, หลอดไฟเสีย, ก๊อกน้ำรั่ว, ประตูชำรุด |
| ปัญหาภายในห้อง | น้ำรั่วซึม, ท่อตัน, เฟอร์นิเจอร์ชำรุด |
| สภาพแวดล้อม | เสียงดังรบกวน, กลิ่นเหม็น, แมลง/หนู, ความสะอาดส่วนกลาง |
| อื่น ๆ | เรื่องอื่นที่ไม่เข้าหมวดข้างต้น |

สถานะคำร้อง: รอดำเนินการ → กำลังดำเนินการ → เสร็จสิ้น

#### รายงานและกราฟสรุปผล (Dashboard สำหรับผู้ดูแล)
- **รายได้-รายจ่าย** ต่อเดือนและต่อปี (กราฟแท่งเปรียบเทียบ และกำไรสุทธิ)
- **อัตราการเข้าพัก** (Occupancy Rate) = ห้องที่มีผู้เช่า ÷ ห้องทั้งหมด
- **อัตราการเข้า-ออก** ของผู้เช่าต่อเดือน (จำนวนผู้เข้าใหม่ / ผู้ย้ายออก)
- **สถานะการชำระเงิน** (สัดส่วนชำระแล้ว / ค้างชำระ / รอตรวจสอบ)
- สรุปจำนวนคำร้องเรียนแยกตามหมวดหมู่

สูตรการคำนวณ:

```
หน่วยที่ใช้   = เลขมิเตอร์ปัจจุบัน - เลขมิเตอร์เดือนก่อน
ยอดรวมบิล    = ค่าเช่า + (หน่วยน้ำ × อัตราค่าน้ำ) + (หน่วยไฟ × อัตราค่าไฟ)
รายได้เดือน   = ผลรวมยอดบิลที่สถานะ "ชำระแล้ว" ของเดือนนั้น
กำไรสุทธิ     = รายได้ - รายจ่ายของเดือนนั้น
อัตราเข้าพัก  = (จำนวนห้องที่มีผู้เช่า ÷ จำนวนห้องทั้งหมด) × 100
```

## สถาปัตยกรรมคลาส (OOP Architecture)

### Model Layer (ข้อมูลและ Business Logic)

| คลาส | รายละเอียด |
| :--- | :--- |
| `User` (Abstract) | `userId`, `username`, `password`, `fullName`, `phone`, `role` และเมธอด `abstract displayDashboard()` |
| `Tenant extends User` | เพิ่ม `roomId`, เมธอด `viewBill()`, `submitPayment()`, `requestTransfer()`, `submitComplaint()` |
| `Admin extends User` | เมธอด `recordMeter()`, `verifyPayment()`, `manageRoom()`, `approveTransfer()` |
| `Applicant extends User` | เมธอดดูห้องว่างและ `requestBooking()` |
| `Room` | `roomId`, `roomNumber`, `roomType`, `baseRent`, `RoomStatus` (AVAILABLE, OCCUPIED, MAINTENANCE) |
| `Bill` | `billId`, `roomId`, `monthYear`, หน่วยน้ำ-ไฟ, `totalAmount`, `PaymentStatus` และเมธอด `calculateTotal(waterRate, elecRate)` |
| `Contract` | `contractId`, `userId`, `roomId`, `startDate`, `endDate`, `deposit`, `ContractStatus` |
| `TransferRequest` | คำขอย้ายห้องและสถานะการพิจารณา |
| `Complaint` | คำร้องเรียน หมวดหมู่ และสถานะ |
| `Expense` | รายจ่ายของหอพัก |

### Service / Data Access Layer

| คลาส | หน้าที่ |
| :--- | :--- |
| `CSVService` | คลาสกลางสำหรับอ่าน/เขียนไฟล์ CSV และจัดการ Exception (`IOException`, `FileNotFoundException`) |
| `AuthManager` | ตรวจสอบการ Login และสิทธิ์เข้าถึงเมนูตามบทบาท |
| `RoomManager` | โหลดรายการห้อง, ค้นหาห้องว่าง, อัปเดตสถานะห้อง, ย้ายห้อง |
| `ContractManager` | จัดการสัญญาเช่า, ตรวจสัญญาใกล้หมดอายุ |
| `BillingManager` | คำนวณค่าน้ำ-ไฟ ออกบิลประจำเดือน และยืนยันการชำระเงิน |
| `ComplaintManager` | รับและอัปเดตสถานะคำร้องเรียน |
| `ReportManager` | รวบรวมข้อมูลสำหรับกราฟ (รายได้-รายจ่าย, อัตราเข้าพัก, อัตราเข้า-ออก) |

## การติดตั้งและใช้งาน (Getting Started)

### สิ่งที่ต้องมี (Prerequisites)
- JDK 17 ขึ้นไป (ตรวจสอบด้วย `java -version` และ `javac -version`)

### ขั้นตอนการรันโปรแกรม

1. โคลนโปรเจ็ค
   ```bash
   git clone https://github.com/<username>/<repo-name>.git
   cd <repo-name>
   ```

2. คอมไพล์โค้ดทั้งหมด

   macOS / Linux
   ```bash
   mkdir -p out
   javac -encoding UTF-8 -d out $(find src -name "*.java")
   ```

   Windows (Command Prompt)
   ```bat
   mkdir out
   dir /s /b src\*.java > sources.txt
   javac -encoding UTF-8 -d out @sources.txt
   ```

3. รันโปรแกรม
   ```bash
   java -Dfile.encoding=UTF-8 -cp out Main
   ```

> ไฟล์ CSV ต้องบันทึกเป็น UTF-8 เพื่อให้ภาษาไทยแสดงผลถูกต้อง

## เช็กลิสต์ความสมบูรณ์ (Quality Checklist)

- [ ] **OOP Structure:** Encapsulation (private fields + getter/setter), Inheritance (`User` → `Tenant` / `Admin` / `Applicant`) และ Polymorphism
- [ ] **Exception Handling:** ดักจับข้อผิดพลาด เช่น ใส่ตัวอักษรในช่องตัวเลขมิเตอร์, บันทึกข้อมูลซ้ำ, ไฟล์ CSV หาย
- [ ] **Separation of Concerns:** แยก UI ออกจาก Logic และการอ่านไฟล์ชัดเจน
- [ ] **Input Validation:** ตรวจสอบข้อมูลก่อนบันทึกลงไฟล์เสมอ (เช่น มิเตอร์ปัจจุบันต้องไม่น้อยกว่ามิเตอร์เดิม, วันสิ้นสุดสัญญาต้องหลังวันเริ่ม)
