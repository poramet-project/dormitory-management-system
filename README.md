# ระบบจัดการหอพัก (Dormitory Management System)

ระบบจัดการหอพักเป็นระบบสำหรับช่วยอำนวยความสะดวกในการบริหารจัดการหอพัก โดยครอบคลุมการจัดการข้อมูลห้องพัก ผู้เช่า สัญญาเช่า ค่าน้ำ-ค่าไฟ การออกใบแจ้งหนี้ การชำระเงิน การแจ้งซ่อม การร้องเรียน การขอย้ายห้อง รวมถึงการสรุปข้อมูลรายรับ-รายจ่ายและอัตราการเข้าพัก

ระบบถูกออกแบบให้มีการแบ่งสิทธิ์การใช้งานตามประเภทของผู้ใช้งาน เพื่อให้แต่ละบทบาทสามารถเข้าถึงฟังก์ชันที่เกี่ยวข้องได้อย่างเหมาะสม โดยพัฒนาด้วยภาษา Java และใช้ Java Swing สำหรับส่วนติดต่อผู้ใช้งาน พร้อมจัดเก็บข้อมูลในรูปแบบไฟล์ CSV

## 2. ผู้ใช้งานระบบ

ระบบแบ่งผู้ใช้งานออกเป็น 3 ประเภท ได้แก่ ผู้สนใจเข้าอาศัย ผู้พักอาศัย และผู้ดูแลหอพัก

### 2.1 ผู้สนใจเข้าอาศัย (Guest / Applicant)

ผู้ใช้งานที่สนใจเช่าห้องพัก สามารถตรวจสอบข้อมูลห้องและส่งคำขอจองห้องได้ โดยมีฟังก์ชันหลักดังนี้

* ดูรายการห้องพักและประเภทห้อง
* ดูราคาค่าเช่ารายเดือน
* ตรวจสอบสถานะห้อง เช่น ว่าง มีผู้เช่า หรืออยู่ระหว่างปรับปรุง
* ส่งคำขอจองห้องพักพร้อมข้อมูลเบื้องต้น

### 2.2 ผู้พักอาศัย (Tenant)

ผู้เช่าสามารถเข้าสู่ระบบเพื่อจัดการและตรวจสอบข้อมูลที่เกี่ยวข้องกับการพักอาศัยของตนเอง ได้แก่

* ดูข้อมูลห้องพักของตนเอง
* ดูข้อมูลสัญญาเช่า เช่น วันเริ่มต้น วันสิ้นสุด ค่าเช่า และเงินประกัน
* ดูประวัติการใช้น้ำและไฟ
* ดูใบแจ้งหนี้ประจำเดือน
* ตรวจสอบสถานะการชำระเงิน
* ส่งหลักฐานการชำระเงิน
* ยื่นคำขอย้ายห้อง
* แจ้งซ่อมหรือร้องเรียน
* ติดตามสถานะของคำร้อง

### 2.3 ผู้ดูแลหอพัก (Admin / Owner)

ผู้ดูแลมีสิทธิ์ในการจัดการข้อมูลหลักของระบบและตรวจสอบการดำเนินงานของหอพัก ได้แก่

* เพิ่ม แก้ไข และเปลี่ยนสถานะห้องพัก
* จัดการข้อมูลผู้เช่า
* จัดการสัญญาเช่า
* บันทึกมิเตอร์น้ำและไฟ
* คำนวณและออกใบแจ้งหนี้อัตโนมัติ
* ตรวจสอบและยืนยันการชำระเงิน
* พิจารณาคำขอย้ายห้อง
* จัดการคำร้องเรียนและแจ้งซ่อม
* บันทึกรายจ่ายของหอพัก
* ดูรายงานและ Dashboard

## 3. ฟังก์ชันหลักของระบบ

### 3.1 ระบบจัดการห้องพัก

สามารถเพิ่ม แก้ไข และตรวจสอบข้อมูลห้องพัก เช่น หมายเลขห้อง ประเภทห้อง ค่าเช่า และสถานะห้อง

สถานะของห้อง ได้แก่

```text
AVAILABLE      ห้องว่าง
OCCUPIED       มีผู้เช่า
MAINTENANCE    อยู่ระหว่างปรับปรุง
```

### 3.2 ระบบจัดการผู้เช่าและสัญญาเช่า

จัดเก็บข้อมูลผู้เช่า เช่น ชื่อ-นามสกุล เบอร์โทรศัพท์ และห้องที่พัก รวมถึงข้อมูลสัญญา ได้แก่ วันเข้าพัก วันสิ้นสุดสัญญา ค่าเช่ารายเดือน เงินประกัน และสถานะของสัญญา

ระบบสามารถตรวจสอบสัญญาที่ใกล้หมดอายุ เช่น ภายใน 30 วัน เพื่อช่วยให้ผู้ดูแลสามารถดำเนินการต่อสัญญาหรือแจ้งผู้เช่าได้

### 3.3 ระบบค่าน้ำและค่าไฟ

ผู้ดูแลสามารถบันทึกเลขมิเตอร์น้ำและไฟในแต่ละเดือน ระบบจะคำนวณจำนวนหน่วยที่ใช้จากเลขมิเตอร์ปัจจุบันและเลขมิเตอร์เดือนก่อนหน้า

```text
หน่วยที่ใช้ = เลขมิเตอร์ปัจจุบัน - เลขมิเตอร์เดือนก่อน
```

จากนั้นนำจำนวนหน่วยไปคำนวณค่าใช้จ่ายตามอัตราที่กำหนด

### 3.4 ระบบใบแจ้งหนี้

ระบบสามารถสร้างใบแจ้งหนี้ประจำเดือนจากข้อมูลค่าเช่า ค่าน้ำ และค่าไฟโดยอัตโนมัติ

```text
ยอดรวมบิล =
ค่าเช่า
+ (หน่วยน้ำ × อัตราค่าน้ำ)
+ (หน่วยไฟ × อัตราค่าไฟ)
```

สถานะของบิล ได้แก่

```text
PENDING                  รอชำระ
WAITING_VERIFICATION     รอตรวจสอบการชำระเงิน
PAID                     ชำระแล้ว
OVERDUE                  ค้างชำระ
```

### 3.5 ระบบชำระเงิน

ผู้เช่าสามารถส่งหลักฐานการชำระเงินเข้าสู่ระบบ จากนั้นผู้ดูแลสามารถตรวจสอบและยืนยันการชำระเงินได้

### 3.6 ระบบขอย้ายห้อง

ผู้เช่าสามารถเลือกห้องที่ต้องการย้าย ระบุเหตุผล และส่งคำขอให้ผู้ดูแลพิจารณา

หากผู้ดูแลอนุมัติ ระบบจะปรับข้อมูลห้องในสัญญาและเปลี่ยนสถานะห้องโดยอัตโนมัติ

```text
ห้องเดิม  → AVAILABLE
ห้องใหม่  → OCCUPIED
สัญญาเช่า → เปลี่ยนเป็นห้องใหม่
```

### 3.7 ระบบแจ้งซ่อมและร้องเรียน

ผู้เช่าสามารถแจ้งปัญหาที่พบ เช่น

* อุปกรณ์ภายในห้องชำรุด
* แอร์ไม่เย็น
* น้ำรั่วหรือท่อตัน
* ปัญหาเฟอร์นิเจอร์
* เสียงดังรบกวน
* ปัญหาพื้นที่ส่วนกลาง

สถานะคำร้อง:

```text
PENDING        รอดำเนินการ
IN_PROGRESS    กำลังดำเนินการ
COMPLETED      ดำเนินการเสร็จสิ้น
```

## 4. Dashboard และรายงาน

ระบบมี Dashboard สำหรับผู้ดูแลเพื่อแสดงข้อมูลภาพรวมของหอพัก เช่น

* รายได้และรายจ่ายรายเดือน
* รายได้และรายจ่ายรายปี
* กำไรสุทธิ
* อัตราการเข้าพัก
* จำนวนผู้เช่าเข้าใหม่
* จำนวนผู้เช่าย้ายออก
* สถานะการชำระเงิน
* จำนวนคำร้องเรียนแยกตามประเภท

สูตรที่ใช้ในการคำนวณ ได้แก่

```text
รายได้เดือน =
ผลรวมยอดบิลที่มีสถานะ PAID

กำไรสุทธิ =
รายได้ - รายจ่าย

อัตราการเข้าพัก =
(จำนวนห้องที่มีผู้เช่า ÷ จำนวนห้องทั้งหมด) × 100
```

กราฟภายในระบบจะพัฒนาด้วย `Graphics2D` และ `JPanel` โดยไม่ใช้ Library ภายนอก

## 6. โครงสร้างระบบ

ระบบแบ่งการทำงานออกเป็นส่วนหลัก เพื่อแยกหน้าที่ของแต่ละส่วนออกจากกัน

```text
User Interface
      ↓
Service / Business Logic
      ↓
Model
      ↓
CSV Storage
```

ตัวอย่างการทำงานของระบบ Login:

```text
LoginPanel
    ↓
AuthManager
    ↓
CSVService
    ↓
users.csv
```

ตัวอย่างการออกใบแจ้งหนี้:

```text
BillingPanel
    ↓
BillingManager
    ↓
Room / Contract / Meter
    ↓
CSVService
    ↓
bills.csv
```

แนวทางดังกล่าวช่วยแยกส่วนติดต่อผู้ใช้งานออกจากส่วนประมวลผลและการจัดเก็บข้อมูล ทำให้สามารถพัฒนาและแก้ไขแต่ละส่วนได้ง่ายขึ้น

## 8. การจัดเก็บข้อมูล

ระบบใช้ไฟล์ CSV เป็นแหล่งจัดเก็บข้อมูลแทนฐานข้อมูล โดยแยกข้อมูลตามประเภท เช่น

```text
data/
├── users.csv
├── rooms.csv
├── contracts.csv
├── bills.csv
├── payments.csv
├── bookings.csv
├── complaints.csv
├── room_transfers.csv
└── expenses.csv
```

ตัวอย่างข้อมูลห้องพัก:

```csv
roomId,roomNumber,roomType,baseRent,status
R101,101,Air-Conditioned,4500,OCCUPIED
R102,102,Fan,3500,AVAILABLE
R103,103,Air-Conditioned,4500,AVAILABLE
```

ตัวอย่างข้อมูลผู้ใช้งาน:

```csv
userId,username,password,fullName,phone,role,roomId
U001,admin,admin123,สมชาย ใจดี,0812345678,ADMIN,-
U002,tenant101,pass101,กิตติพงษ์ รักสงบ,0898765432,TENANT,R101
U003,applicant1,pass123,อนันต์ มุ่งมั่น,0861112233,APPLICANT,-
```
